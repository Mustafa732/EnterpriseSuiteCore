# EnterpriseSuiteCore
Bitware ERP - Migrated from WebForms to .NET 8 MVC + Razor Pages

## Structure (Same as old EnterpriseSuite)
- Common: Shared utilities
- DAL: Data Access Layer
- ERP: Main Web Application (MVC + Razor Pages)
- Fnl.BusinessAccessLayer: Business Logic
- Fnl.Core: Core Entities
- Fnl.QueryResourceLibrary: Query Helpers
- Fnl.SecondarySale: Secondary Sales Module
